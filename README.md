# 🗂️ simple-task-manager

A Kanban-style task management application for organizing work into clear stages such as **Todo**, **Doing**, and **Done**.

Built to demonstrate clean UI design, component-based architecture, and state management using modern frontend tools.

---

## 🚀 Features

- Create, edit, and delete tasks
- Fixed Kanban columns (Todo / Doing / Done)
- Move tasks between columns
- Persistent storage (localStorage or backend)
- Responsive, clean UI

---

## 🛠️ Tech Stack

- **Vue 3**
- **Vue packages: VueDraggable, VueUse.**
- **TypeScript**
- **Vite**
- **backend: Supabase**

---

## 🧠 Key Concepts

- Component-based architecture
- Drag and drop functionality
- CRUD operations
- Task lifecycle handling
- Responsive layout design
